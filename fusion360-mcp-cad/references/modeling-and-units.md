# 参数、单位与实体引用

## 单位边界

保留用户输入单位及原值；规划可统一用 mm，但不能假定 Fusion 的界面单位等于 API 内部单位。常见 Fusion API 长度为 cm、角度为 rad、体积为 cm³；每个方法的输入和返回值仍以 API 文档为准。

- 支持单位表达式时优先使用如 `40 mm`、`1 in` 的表达式。
- 必须传内部裸数值时显式换算：40 mm → 4 cm；1 in → 2.54 cm；90° → π/2 rad。
- 输出转换也需明确：cm → mm 乘 10，cm² → mm² 乘 100，cm³ → mm³ 乘 1000。
- 不对无量纲数量、角度或已带单位的值重复换算。读写时记录所用坐标系。
- 区分尺寸公差、浮点比较容差和制造补偿；按用户验收要求比较，不用打印间隙代替数值容差。

验收测量来自最终几何，不只回显输入参数。用指定坐标系下 40 mm 的模型尺寸核对端到端单位转换。

## 参数与设计意图

关键尺寸形成命名用户参数，引用关系使用表达式。例如外宽改变后，孔中心仍距边 5 mm。修改参数后重计算，检查特征健康和几何变化；若工具或模型历史不支持参数编辑，说明限制并选择适合的直接建模方式。

对驱动草图检查几何/尺寸约束，优先以原点、对称和基准定位。导入参考、投影、样条等按用途验证，不以“全部 Fix”替代参数化。装饰圆角优先靠后；影响抽壳或后续轮廓的圆角按功能依赖安排。

布尔先检查目标和工具体的位置、重叠及预期实体数。优先使用适当的贯穿或到面终止条件，不统一增加 0.01 mm 改变实际零件。对完全贴合、相切和微小碎面按具体拓扑诊断。

## 创建与修改现有模型

新建简单零件可以默认 XY/世界原点，修改现有模型先读取其基准、设计历史和局部坐标。识别目标文档、组件、装配实例、Body 及目标特征，避免默认选择集合的第 0 项。

名称可能重复，集合序号可能改变；结合组件路径、几何类型、位置和尺寸核对目标。实体 token 按 API 规则解析，取得对象后检查有效性和归属，不比较 token 字符串来断言实体身份永久稳定。实例上下文中的几何需处理局部与装配变换，避免重复应用变换。

修改前记录必要检查点：文档身份、目标引用、关键尺寸、相关实体/特征数，有历史时加时间线位置。重连、用户编辑或文档切换后重新读取，检查点不是可还原快照。

## 保存与导出

按用户请求保存和导出，说明当前文档是否已保存。保存的云端位置、版本行为和可导出格式以实际许可、文档及工具能力为准。

- 原生设计用于保留可编辑参数和历史；导出后重新核对文件及必要元数据。
- STEP 用于交换实体几何，不保证保留原始特征树。
- STL/3MF 用于网格和打印，检查导出单位、离散精度与实体覆盖；STL 本身不可靠地携带单位语义。

已有文件冲突按用户约定处理。没有生成文件时不提供虚构路径；缺少对应导出能力时交付模型位置与未完成项。
