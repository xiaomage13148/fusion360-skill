# 视觉校验规范（多模态模型通用）

## 设计原则

1. **双通道互补**：数值通道（MCP 测量）负责精确尺寸与拓扑判定；图像通道（截图）负责外观、方向、位置、装配关系的直观核对。
2. **能力自适应**：任何模型都可执行本规范。具备图像理解能力时自动完成图像通道分析；不具备时图像通道降级为「捕获并交付用户确认」，数值通道必须完整执行。
3. **几何内核优先**：图像仅做外观校验，共面、自相交、布尔失败等拓扑错误必须依赖 MCP 测量脚本与几何检查结论，**图片不能替代 Fusion 内核几何校验**。

## 每次特征完成后的固定动作

```
特征执行结束
  → 脚本测量：单独调用一次 fusion_mcp_execute(script)，print 关键尺寸（包围盒、体积、孔径、间距、壁厚）
  → 捕获截图：fusion_mcp_read { queryType: "screenshot", direction: "iso-top-left" }
  → 双通道分析
      ├─ 视觉模型：分析截图 + 比对测量数值 → 输出视觉自检结论
      └─ 非视觉模型：仅比对测量数值 → 标注「数值校验，图像待人工确认」
  → 输出自检报告，等待用户确认
```

**截图规范**（通过 `fusion_mcp_read` 的 `screenshot` 查询）：

- 视图方向固定为**正交等轴测**：`direction: "iso-top-left"`（或 `iso-top-right`），不依赖用户当前视角。
- `width` / `height` 建议 ≥ 1024 px，便于观察细节；`transparentBackground: false` 便于看清轮廓。
- 截图前隐藏基准面、草图标记、尺寸标注、原点标记，画面只保留实体。
- 截图以 base64 编码 PNG 返回：视觉模型直接分析图像，非视觉模型交用户人工确认。
- 单轮对话最多 1 张截图，避免上下文膨胀。
- 需要观察内部结构时，单独捕获剖视图，不与外观截图混在一轮。

## 视觉检查清单

| 检查项 | 判定标准 | 不通过时的动作 |
|---|---|---|
| 草图约束完整性 | 草图完全约束，无欠约束自由度 | 补齐约束后重建该草图 |
| 实体位置与方向 | 拉伸方向、偏移方向、坐标位置与参数一致 | 撤销当前特征，修正方向/位置 |
| 无效几何 | 无自相交、无零厚度面、无退化边 | 修正轮廓，避免共面与微小重叠面 |
| 特征数量与形状 | 实体数目、凸台/凹槽数量与规划一致 | 检查是否误选旧几何体 |
| 比例合理性 | 外形比例与参数表吻合，无目视明显失调 | 重新核对参数，重做当前特征 |
| 最小壁厚 | ≥ 1.2 mm（FDM 默认） | 加厚或调整结构，见 `3d-print-rules.md` |

## 自检报告模板

```markdown
### 第 N 步自检报告

**操作**：<本次执行的单个特征>
**MCP 执行结果**：<成功 / 失败 + 特征 ID>

**测量数据**
| 目标 | 期望值 | 实测值 | 偏差 | 结论 |
|---|---|---|---|---|
| 总长 | 40.00 mm | 40.00 mm | 0.00 | ✓ |
| ... | | | | |

**视觉自检**（视觉模型）
- 外观与比例：✓ 与参数一致
- 特征位置/方向：✓ 顶部居中
- 无效几何：✗ 未发现 / ✓ 发现（描述）

**校验结论**：通过 / 不通过（原因）
**下一步计划**：<下一步特征>（等待用户确认）
```

非视觉模型将「视觉自检」段替换为：

```markdown
**数值校验**：本次以脚本测量数据为准，截图见上方图像，请人工确认外观是否符合预期。
```

## 无视觉能力模型的降级策略

当模型无法读取图像时，按以下方式补足校验强度：

1. **加密度量**：每个特征至少测量 2 个正交方向尺寸 + 1 个位置尺寸，用包围盒（Bounding Box）数据交叉验证。
2. **脚本替代目视**：用测量脚本读取 `BRepBody.boundingBox`、体积、面/边数量与关键点位坐标，用数值替代目视判断；干涉判定用体包围盒相交 + 体积校验完成。
3. **交付用户确认**：每步截图仍要捕获并附在对话中（base64 图像），请用户人工确认后再继续。
4. **不臆测图像内容**：绝不编造「看起来没问题」之类的图像结论，只陈述数值事实。

## 建模路径约束（避免「一张图直接生成复杂模型」）

- 不要从单张图片一次性生成完整复杂模型；建模始终使用分步参数化流程。
- 图片仅作为需求输入或外观校验，不作为尺寸来源；尺寸以用户参数表与 MCP 测量为准。
