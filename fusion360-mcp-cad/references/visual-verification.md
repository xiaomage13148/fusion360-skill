# 几何与图像验证

## 证据与结论

工具返回成功只表示该调用成功，不证明模型满足设计要求。修改后以独立读取的实际几何和健康状态验证；关键检查失败时不继续依赖修改。

| 项目 | 依据 | 限制 |
|---|---|---|
| 外部尺寸 | 指定坐标系中的尺寸或包围盒 | 包围盒不能替代孔径、孔距、孔深和壁厚 |
| 孔径/位置/间距 | 对应几何测量，并与特征参数交叉核对 | 不只回显创建时的输入 |
| 草图约束 | API 状态和必要的自由度检查 | 图像无法证明完全约束 |
| 实体与特征健康 | 有效性、特征健康状态、错误/警告及重计算结果 | 正体积不能单独证明整体拓扑无误 |
| 干涉 | 受支持的干涉分析，或已核实的实体求交方法 | 包围盒相交仅做初筛；区分接触和实际体积重叠 |
| 壁厚 | 适合目标几何的局部测量或厚度分析 | 面距/局部抽查标明位置；不能冒充全局最小厚度 |
| 形状与方向 | 真实模型的合适视图 | 不证明精确尺寸或内核有效性 |

检查状态使用：**通过、不通过、未验证、不适用**。记录期望值、实测值、单位、容差、依据和覆盖范围。能力不足或数据缺失写未验证，不把未发现问题当作验证通过。

## 图像策略

主体、关键开孔、内腔和外观变化后按需截图，不为每个草图固定截图，也不限制每轮只能一张。等轴测看整体；正投影看孔位；剖视图看内部结构。隐藏参考物、切换相机或剖切状态前注意其是否修改会话，按需记录并恢复，不能把这些操作塞入承诺纯只读的脚本。

截图工具返回图像，不表示模型实际获得了可理解的图像内容。宿主能传递图像且模型能读取时才给视觉结论；否则可以提供用户可查看的附件，并标记外观未验证。无图像不强制中断所有可完成的数值检查。

图片可作为外形输入。有比例尺或用户给定参考尺寸时可辅助估算，明确不确定性；制造关键尺寸不能从无标定图片中臆测。AI 渲染或编辑后的图片不能用于几何验收。

## 简短报告示例

| 检查 | 期望 | 实测/状态 | 依据 |
|---|---|---|---|
| 外宽 | 40 mm，±0.05 mm | 40.00 mm，通过 | 最终实体在组件 X 方向的范围 |
| 孔径 | 3.2 mm，±0.05 mm | 3.20 mm，通过 | 对应圆柱面测量 |
| 内腔壁厚 | ≥1.6 mm | 抽查 2 处通过，其余未验证 | 标明测量位置 |
| 干涉 | 不相交 | 未验证 | 当前无可靠实体求交结果 |

自主模式只汇报关键阶段和异常，逐步模式再逐步展开。用户要求完整报告时补齐所有验收项和实际交付状态。
