# 错误分类与修复策略

## 通用原则

1. 报错时用 `fusion_mcp_update` + `featureType: "undo"` **仅撤销当前这一步**，保留前面所有已完成并通过校验的实体。
2. 输出错误诊断（错误类型 + 触发原因 + 修复方案），不要清空整个文档重来。
3. 同一错误最多重试 2 次；两次都失败则更换实现方式（换特征类型/换轮廓/换基准面）。
4. 无法自行修复时，向用户报告「现象 + 已尝试方案 + 建议」，不进入无限重试。
5. 修复后必须重新执行完整的单步闭环（建模 → 测量 → 截图 → 自检）。
6. 脚本异常信息（Python traceback / Fusion API 报错）是首要诊断依据：不要吞掉异常，也不要只截取「执行失败」几个字。

## 错误分类表

### 1. 草图未完全约束（Under-constrained sketch）

- **现象**：草图存在自由度，尺寸随参数漂移；后续拉伸结果与预期尺寸不符。
- **根因**：缺少尺寸标注或几何约束；未用原点定位。
- **修复**：补齐尺寸/几何约束；将草图关键点与原点建立重合/对称约束；必要时重画草图而不是打补丁。
- **预防**：草图完成后立即检查约束状态，未完全约束不进入拉伸。

### 2. 圆角/倒角超限（Fillet failure）

- **现象**：圆角创建失败或提示半径过大；边被吞掉、产生尖锐碎面。
- **根因**：半径大于相邻面尺寸的一半；相邻边交汇处容不下圆角；圆角在错误时序提前创建。
- **修复**：减小半径至「相邻最小边长的 1/2」以下；分边组逐个执行圆角；把圆角移到最后阶段执行。
- **预防**：严格遵守时序铁律——主体 → 切除/打孔/阵列 → 最后圆角。

### 3. 布尔运算失败（Boolean failure）

- **现象**：Join/Cut 报错或产生异常结果；实体消失、出现零厚度面。
- **根因**：两实体无重叠（间隙）；完全共面贴合（0 厚度接触）；微小重叠面；自相交轮廓。
- **修复**：
  - 无重叠 → 调整尺寸，保证重叠量 ≥ 0.01 mm；
  - 共面 → 让切割体穿出目标面，避免仅在表面相切；
  - 自相交 → 修正草图轮廓，删除退化线段。
- **预防**：布尔前用脚本读取实体清单并 `print` 确认实体存在；多实体合并改为分步布尔。

### 4. 拉伸无效轮廓（Extrude invalid profile）

- **现象**：无法选中轮廓或拉伸结果为空。
- **根因**：草图轮廓未闭合；轮廓自相交；轮廓不在当前基准面。
- **修复**：闭合轮廓；检查是否有多余的重复线段；确认草图平面与拉伸方向。

### 5. 实体选择错误（Wrong body selected）

- **现象**：操作作用在旧几何体上；实体数量莫名变化。
- **根因**：隐式选择；文档中存在多个 Body/Component 未区分。
- **修复**：先 `undo` 撤销当前操作，再用脚本读取并 `print` 实体清单，显式指定目标实体名称/ID 重新执行。
- **预防**：多零件使用独立 Component 管理，命名清晰。

### 6. MCP 连接失败 / 服务无响应

- **现象**：工具调用超时、连接被拒绝、返回非 JSON 错误。
- **根因**：Fusion 360 未启动、MCP 插件未加载、端点路径/端口不匹配（正确端点为 `http://127.0.0.1:27182/mcp`）、上一次调用仍在执行中。
- **修复**：
  1. 运行 `scripts/check_mcp_server.py --tools` 探测端点；
  2. 提示用户确认 Fusion 360 已启动且 MCP 插件已加载；
  3. 确认端点地址包含 `/mcp` 路径；
  4. 等待片刻后重试单次调用，不要并发重试。

### 7. 测量结果与预期偏差过大

- **现象**：实测尺寸与参数表偏差超过公差。
- **根因**：单位错误（cm/inch 混用）；参数传递错位；特征建在错误的基准面。
- **修复**：核对单位换算；核对参数顺序；确认基准面与草图平面；`undo` 后重建当前特征。

### 8. 建模脚本执行异常（Python / API 错误）

- **现象**：`fusion_mcp_execute` 返回 traceback：`NameError`、`AttributeError`、`TypeError`、`RuntimeError`，或提示找不到 `run` 函数。
- **根因**：凭记忆写 API（名称/签名错误）；对象类型未 `cast` 转换；枚举值拼写错误；脚本缺少 `def run(_context: str):` 入口。
- **修复**：
  1. 用 `fusion_mcp_read` + `queryType: "apiDocumentation"` 查询正确 API（`apiCategory: "class"` 定位类，`"member"` 查方法与枚举）；
  2. 按查询结果修正脚本，改名、改参数、补 `cast`；
  3. 若失败发生在特征创建中途，先 `fusion_mcp_update` + `undo` 回退，再执行修正后的脚本。
- **预防**：任何建模脚本都先查 API 文档；入口函数签名严格保持 `def run(_context: str):`；不捕获异常。

## 诊断输出模板

```markdown
**错误类型**：<分类名>
**现象**：<工具返回的关键错误信息，仅摘录关键行；脚本异常附 traceback 末行>
**根因判断**：<依据>
**已执行动作**：`fusion_mcp_update undo` 撤销步骤 N，前序 N-1 步实体保持完好
**修复方案**：<具体操作步骤>
**是否继续**：修复后继续第 N 步 / 等待用户指示
```
