# 失败与结果未知时的恢复

## 先确认状态，再决定动作

执行错误、连接中断和超时都不证明“未发生修改”。禁止无条件 undo、清空文档或直接重发修改。先保留 traceback/关键错误，重新核对活动文档、目标和交互状态，再与修改前检查点比较。时间线数量或实体数量单项不够时，读取目标特征、参数和几何。

| 观察到的状态 | 动作 |
|---|---|
| 目标状态未改变，能确认修改未提交 | 不 undo；修正原因后重试该步骤 |
| 已完成预期修改且验证通过 | 记为已完成，不重复创建 |
| 已部分修改或生成错误几何 | 仅在能确认本次事务归属及撤销范围时恢复；否则停止依赖修改并报告 |
| 文档被切换、用户介入、引用失效或状态仍未知 | 不猜测重试/回滚；继续只读定位，必要时请用户明确目标或恢复位置 |

`canUndo: true`、时间线多一项、脚本只建一个特征，都不能单独证明最近事务属于本次操作。适配器事务边界未实测时，不承诺一次 undo 恢复一步。不得跨越用户手动操作撤销。恢复后重新读取并验证目标状态。

修改超时后等待或查询正在运行的操作，避免并发执行同一文档修改；重连不会自动恢复旧会话中的目标引用。只有确认原修改未生效，才允许重试。

## 按原因修复

| 错误 | 诊断与修复 |
|---|---|
| 草图轮廓/约束错误 | 检查闭合、自交、重复线段和约束冲突；补齐设计需要的尺寸与几何关系 |
| 圆角或抽壳失败 | 查看局部几何与健康信息，调整半径、边组或依赖顺序；最短边的一半不是通用可行性判据 |
| 布尔失败 | 核对实体、坐标变换和真实交叠，避免相切与退化；不任意扩大关键尺寸 |
| 错选实体 | 先确认实际影响和事务归属，再恢复；重新解析并核对目标 |
| 尺寸偏差 | 检查 API 单位、坐标系、表达式和最终几何；修正后重测 |
| API/脚本错误 | 查当前 API 文档和执行入口；保留原错误，不用捕获异常后打印成功 |
| 只读越权 | 将检查与修改分开；只读脚本不能通过文本命令绕过限制 |
| 交互命令阻塞 | 读取命令状态；不自动放弃用户未完成的输入，待其完成或按已授权方式退出 |
| MCP 无响应 | 查询宿主连接与操作状态；可选 HTTP 诊断不能证明几何操作是否完成 |

同一原因修正后最多重试 2 次；仍失败则换有依据的实现方式。替代方案若改变关键设计或范围，先说明影响并澄清。无法可靠恢复时交付已知状态、已尝试动作和具体缺失信息，避免无限重试。

诊断汇报包含：错误现象、证据、当前模型状态、实际执行的恢复动作、验证结果和下一步。没有执行撤销时不使用“已回滚”措辞。
