# 当前 Fusion MCP 适配注意事项

只在使用 `fusion_mcp_read` / `fusion_mcp_execute` / `fusion_mcp_update` 风格服务，且当前工具说明不足时读取。工具名称、参数、枚举和限制以实时 schema 为准；这里不保存接口定义副本。服务资源已覆盖的信息不必重复加载。

## 脚本与响应

该适配器通过执行工具提交 Python，Fusion API 才负责实际几何操作。入口、只读声明和异常处理方式应先从当前工具描述确认；历史服务约定入口为 `def run(_context: str):`，`print()` 输出随执行结果返回。

根据真实响应解析外层 MCP `isError`、文本内的 JSON 和业务 `success`；不能只看 HTTP 成功。历史服务将脚本输出放在 `message` 中，当前响应不一致时先检查结构，不从空字段推断成功。

对纯测量脚本使用服务提供的只读标记。只读脚本不创建、修改或删除几何，不通过文本命令绕过限制。改相机、隐藏草图或切换可见性也可能改变会话状态，应与只读几何测量分开，并按需恢复视图。

该服务可能要求异常直接向外传播；遵循当前说明，保留 traceback，不吞异常或打印成功掩盖失败。MCP 执行 schema 不包含全部 `adsk` API，具体类、方法、单位仍需按需查文档。

## 状态与恢复

- 修改前检查活动文档和交互命令；用户正在编辑时，不自动取消其未完成输入。只读检查能否执行以当前服务约束为准。
- undo 作用于活动文档最近一次已提交事务。一次脚本调用与事务数的关系尚未通过本仓库的真实建模测试，不保证“一次 undo 恰好恢复一步”。
- `canUndo` 只说明有可撤销事务，不说明它属于本次操作。报错或超时后先读取状态，再依 [恢复流程](error-recovery.md) 决定动作。
- 文档切换、用户手动修改、重连后重新确认目标与引用；不并发重发修改。
- 保存、关闭和导出遵守工具的具体授权字段和用户意图，不将用户未做出的确认填为 true。

## 接入诊断

历史本地 HTTP 端点示例：`http://127.0.0.1:27182/mcp`；不是所有服务的固定地址。优先复用宿主连接。可选 `scripts/check_mcp_server.py` 仅诊断其明确支持的 Streamable HTTP 子集，不支持 stdio、旧式 HTTP+SSE 双端点、OAuth 或服务端向客户端发起的 RPC。
